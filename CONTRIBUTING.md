# Contributing

Contributions are welcome. Please open an issue to discuss large changes before submitting a pull request.

## Development setup

Use Node.js 20 or newer. Run `npm install`, then `npm run check` before submitting. Add tests for behavior changes; use scripted models and mocked fetch calls so routine tests remain deterministic and offline.

## Pull requests

- Keep changes focused and document public API changes.
- Include tests and update the changelog for user-visible changes.
- Never commit credentials, generated output, or unrelated formatting changes.
- Describe security impact and known limitations where relevant.

By contributing, you agree to follow the project [Code of Conduct](CODE_OF_CONDUCT.md).
